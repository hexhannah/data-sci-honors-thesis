This repository is for Hannah Brown's Data Science Honors Thesis at UC Berkeley.

## Directory Structure

This repo contains a few subfolders which contain the elements of this project.

| Folder | Description |
|-----|-----|
| `data`  | Survey results in CSV format |
| `notebooks`  | Jupyter Notebook files for analyzing data and creating interface |
| `output`  | Thesis document |
| `presentations` | Various presentations given relating to thesis work |
| `notes` | Notes from evaluations and analysis |
